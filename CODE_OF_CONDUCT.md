# Code of Conduct

Plasma Git Watcher is a small project, and everyone who takes part in it is expected to keep it a
friendly place. The project follows the [KDE Community Code of Conduct](https://kde.org/code-of-conduct/),
which applies to the issues, pull requests and discussions of this repository.

## Expected

- Be respectful and patient, also when you disagree.
- Keep the discussion about the project and the code, not about people.

## Not accepted

- Insults, harassment, personal attacks, or discriminatory jokes and language.
- Publishing someone's private information without their permission.
- Spam, trolling, or repeatedly derailing a discussion.

## Reporting

To report behaviour that breaks this code of conduct, e-mail the maintainer at vitalyle@protonmail.com.
Reports are handled privately.
